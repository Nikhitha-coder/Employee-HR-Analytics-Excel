# Employee HR Analytics Dashboard

📊 Project Overview

This project analyzes employee workforce, salary, performance, attendance, and compensation data using Microsoft Excel.

The goal is to transform raw employee data into meaningful insights through data cleaning, calculations, PivotTables, and an interactive HR analytics dashboard.

🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- Excel Charts
- Excel Formulas
- Data Cleaning & Transformation
- HR Analytics

📁 Dataset

The dataset contains information about "5,000 employees", including:

- Employee ID
- Gender
- Department
- Designation
- Joining Date
- Date of Birth
- Basic Salary
- Bonus
- Attendance %
- Performance Score
- City
- Manager ID

Additional calculated fields were created for:

- Total Compensation
- Performance Category
- Attendance Category
- Joining Year

📈 Dashboard Analysis

The dashboard provides insights into:

- Employee count by department
- Average basic salary by department
- Average performance score by department
- Attendance category distribution
- Employee distribution by city
- Gender distribution
- Average total compensation by city
- Employee joining trend by year
- Salary and performance comparison by department
- Workforce distribution by department

🔍 Key Insights

- The organization has "5,000 employees" across multiple departments and cities.
- The overall average basic salary is approximately "₹73,036".
- The overall average total compensation is approximately "₹90,501".
- The overall average performance score is approximately "70.02".
- The overall average attendance is approximately "79.82%".
- IT has the highest average total compensation among the departments.
- Support has the lowest average total compensation among the departments.
- Female employees represent approximately "51%" of the workforce, while male employees represent approximately "49%".
